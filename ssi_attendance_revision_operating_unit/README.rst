Glue module that adds Operating Unit support to the Attendance Revision module.
Extends ``attendance_revision`` and ``attendance_revision.detail`` with
``mixin.single_operating_unit``. When schedule details are auto-loaded via
``action_reload_schedule``, the ``operating_unit_id`` from the parent revision
document is propagated to each detail line.
